# Build-input tracer (level 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI, `./trace <app> --from A --to B [--task compileJava|fingerprint]`, that lists which commits in a git range changed an app's build inputs, using Gradle task cache keys as the verdict and bazel-diff as an informational second opinion, on a Gradle + Bazel multi-module Java repo built for learning Gradle.

**Architecture:** One source tree, two build descriptions. `build-logic/` (Gradle included build, Java plugins) holds the conventions and a cacheable `fingerprint` task. `tools/tracer/` is a Java CLI that materialises each commit in a throwaway git worktree, runs `gradlew <task> -Dorg.gradle.caching.debug=true` to read the task's cache key and per-input fingerprints, runs `bazel-diff` for the Bazel column, and compares adjacent commits. `tools/scenarios.sh` replays seven teaching commits and asserts the expected verdicts.

**Tech Stack:** Java 21 bytecode on JDK 25, Gradle 9.8.1 (wrapper), Bazel 9.1.0 with rules_java 9.9.0 and rules_jvm_external 7.2, JUnit Jupiter 6.1.3, Gradle TestKit, bazel-diff v60.0.0 (prebuilt binary), commons-lang3 3.18.0 (3.14.0–3.17.x carry CVE-2025-48924), gson 2.10.1.

**Spec:** `docs/superpowers/specs/2026-10-16-build-input-tracer-design.md`. Read sections 4 (module graph), 5 (CLI), 8 (scenario table) and 14 (verified facts and amendments) before starting. Fifteen tasks, one commit each.

**Conventions for every task:** work on branch `feature/level1-input-tracer`; tests first; run the task's test command before committing; one logical change per commit, ≤ 400 hand-written lines (generated files — `gradlew`, `gradle/wrapper/*`, `*.lockfile`, `maven_install.json` — do not count); docs for a component land in the same commit as the component; no `Co-Authored-By` trailers; commit body says *why*.

`build-logic/src/test/java/io/joeyang/tracer/buildlogic/GradleProject.java` (TestKit shares one build cache across every test method by default; three tests compile byte-identical sample code, so without a per-project cache the last one would see `FROM_CACHE` where it asserts `SUCCESS`):
```java
package io.joeyang.tracer.buildlogic;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import org.gradle.testkit.runner.BuildResult;
import org.gradle.testkit.runner.GradleRunner;

/** Writes a throwaway Gradle project that can apply the convention plugins under test. */
final class GradleProject {
    static final String CATALOG = """
            [versions]
            junit = "6.1.3"
            [libraries]
            junit-bom = { module = "org.junit:junit-bom", version.ref = "junit" }
            junit-jupiter = { module = "org.junit.jupiter:junit-jupiter" }
            junit-platform-launcher = { module = "org.junit.platform:junit-platform-launcher" }
            """;

    final Path dir;
    final Path cacheDir;

    /** Each project gets its own local build cache, so test methods never see each other's FROM-CACHE hits. */
    GradleProject(Path dir) throws IOException {
        this(dir, dir.resolve(".build-cache"));
    }

    /** @param cacheDir local build cache for this project; two projects sharing it can be used to test FROM-CACHE across locations */
    GradleProject(Path dir, Path cacheDir) throws IOException {
        this.dir = dir;
        this.cacheDir = cacheDir;
        Files.createDirectories(dir);
        write("settings.gradle.kts", """
                dependencyResolutionManagement {
                    repositories { mavenCentral() }
                }
                buildCache {
                    local { directory = file("%s") }
                }
                rootProject.name = "sample"
                """.formatted(cacheDir.toString().replace("\\", "/")));
        write("gradle/libs.versions.toml", CATALOG);
        write("gradle.properties", "org.gradle.caching=true\n");
    }

    GradleProject write(String relative, String content) throws IOException {
        Path target = dir.resolve(relative);
        Files.createDirectories(target.getParent());
        Files.writeString(target, content);
        return this;
    }

    BuildResult run(String... args) {
        return runner(args).build();
    }

    BuildResult runAndFail(String... args) {
        return runner(args).buildAndFail();
    }

    private GradleRunner runner(String... args) {
        return GradleRunner.create()
                .withProjectDir(dir.toFile())
                .withPluginClasspath()
                .withArguments(args)
                .forwardOutput();
    }
}
```

```java
package io.joeyang.tracer.buildlogic;

import org.gradle.api.GradleException;
import org.gradle.api.Plugin;
import org.gradle.api.Project;
import org.gradle.api.artifacts.MinimalExternalModuleDependency;
import org.gradle.api.artifacts.VersionCatalog;
import org.gradle.api.artifacts.VersionCatalogsExtension;
import org.gradle.api.artifacts.dsl.DependencyHandler;
import org.gradle.api.provider.Provider;
import org.gradle.api.tasks.bundling.Jar;
import org.gradle.api.tasks.compile.JavaCompile;
import org.gradle.api.tasks.testing.Test;

/**
 * Conventions shared by every module: Java 21 bytecode, JUnit platform tests,
 * reproducible jars and dependency locking. Library and application plugins build on it.
 */
public final class JavaBaseConventionPlugin implements Plugin<Project> {
    static final int RELEASE = 21;

    @Override
    public void apply(Project project) {
        project.getPluginManager().apply("java");
        project.getTasks().withType(JavaCompile.class).configureEach(task -> {
            task.getOptions().getRelease().set(RELEASE);
            task.getOptions().setEncoding("UTF-8");
        });
        project.getTasks().withType(Jar.class).configureEach(jar -> {
            jar.setPreserveFileTimestamps(false);
            jar.setReproducibleFileOrder(true);
        });
        project.getTasks().withType(Test.class).configureEach(Test::useJUnitPlatform);
        addJUnit(project);
        project.getDependencyLocking().lockAllConfigurations();
    }

    private static void addJUnit(Project project) {
        VersionCatalog libs = catalog(project);
        DependencyHandler deps = project.getDependencies();
        deps.addProvider("testImplementation", deps.platform(library(libs, "junit-bom")));
        deps.addProvider("testImplementation", library(libs, "junit-jupiter"));
        deps.addProvider("testRuntimeOnly", library(libs, "junit-platform-launcher"));
    }

    static VersionCatalog catalog(Project project) {
        VersionCatalogsExtension catalogs = project.getExtensions().findByType(VersionCatalogsExtension.class);
        if (catalogs == null) {
            throw new GradleException("tracer.java-base needs the 'libs' version catalog (gradle/libs.versions.toml)");
        }
        return catalogs.find("libs").orElseThrow(
                () -> new GradleException("version catalog 'libs' not found; expected gradle/libs.versions.toml"));
    }

    private static Provider<MinimalExternalModuleDependency> library(VersionCatalog libs, String alias) {
        return libs.findLibrary(alias).orElseThrow(
                () -> new GradleException("alias '" + alias + "' is missing from gradle/libs.versions.toml"));
    }
}
```

```markdown
## Layout
- `settings.gradle.kts` includes the `build-logic` build (`pluginManagement.includeBuild`) and declares
  Maven Central once for every project (`FAIL_ON_PROJECT_REPOS`).
- `gradle/libs.versions.toml` is the only place a dependency version appears. `build-logic` imports the same
  file so plugins can add JUnit from it.
- `gradle.properties` turns the build cache on (`org.gradle.caching=true`); the tracer depends on that.

## Convention plugins (`build-logic`, written in Java)
| id | applies | adds |
|---|---|---|
| `tracer.java-base` | `java` | `--release 21`, UTF-8, JUnit platform + JUnit from the catalog, reproducible jars, `lockAllConfigurations()` |
| `tracer.java-library` | base + `java-library` | `api` vs `implementation` separation |
| `tracer.java-application` | base + `application` | `run`, `installDist`; module sets `application.mainClass` |

## Dependency locking
Every module locks all configurations. Regenerate after a version change:

    ./gradlew <module>:dependencies --write-locks

## Tests
`./gradlew -p build-logic test` runs the TestKit tests (they need network for JUnit).
```

```java
package io.joeyang.tracer.utils;

import java.util.Locale;

/** Small text helpers shared by every module. */
public final class Formatter {
    private Formatter() {}

    /**
     * Formats cents as dollars: 1234 → "$12.34". The sign goes in front: -750 → "-$7.50".
     *
     * @throws IllegalArgumentException if {@code cents} is {@code Long.MIN_VALUE}, which has no
     *     representable absolute value
     */
    public static String money(long cents) {
        if (cents == Long.MIN_VALUE) {
            throw new IllegalArgumentException("cents must be greater than Long.MIN_VALUE");
        }
        long abs = Math.abs(cents);
        String sign = cents < 0 ? "-" : "";
        return sign + "$" + (abs / 100) + "." + String.format(Locale.ROOT, "%02d", abs % 100);
    }

    /** Right-pads {@code text} with spaces to {@code width}; longer text is returned unchanged. */
    public static String pad(String text, int width) {
        if (text == null) {
            throw new IllegalArgumentException("text must not be null");
        }
        if (width < 0) {
            throw new IllegalArgumentException("width must be >= 0, got " + width);
        }
        if (text.length() >= width) {
            return text;
        }
        return text + " ".repeat(width - text.length());   // SCENARIO S1 edits this line (body only)
    }
}
```

```python
def junit5_test_suite(name, srcs, deps = [], runtime_deps = [], resources = [], resource_strip_prefix = None, **kwargs):
    """One java_test per *Test.java in srcs, executed through org.junit.platform.console.ConsoleLauncher.

    Sources that are not tests (fakes, helpers) and resources go into <name>_support, a testonly library
    every test depends on. The suite target <name> groups all tests.
    """
    tests = [s for s in srcs if s.endswith("Test.java")]
    helpers = [s for s in srcs if not s.endswith("Test.java")]
    support = []
    if helpers or resources:
        java_library(
            name = name + "_support",
            testonly = True,
            srcs = helpers,
            resources = resources,
            resource_strip_prefix = resource_strip_prefix,
            deps = deps + _JUNIT_API,
            javacopts = JAVACOPTS,
        )
        support = [":" + name + "_support"]
    targets = []
    for src in tests:
        class_name = src.removeprefix("src/test/java/").removesuffix(".java").replace("/", ".")
        target = class_name.rsplit(".", 1)[-1]
        kwargs.setdefault("size", "small")
        java_test(
            name = target,
            srcs = [src],
            deps = deps + support + _JUNIT_API,
            runtime_deps = runtime_deps + _JUNIT_RUNTIME,
            javacopts = JAVACOPTS,
            main_class = "org.junit.platform.console.ConsoleLauncher",
            use_testrunner = False,
            args = ["execute", "--select-class", class_name, "--disable-banner", "--details=summary", "--fail-if-no-tests"],
            **kwargs
        )
        targets.append(":" + target)
    native.test_suite(name = name, tests = targets)
```

Background for the engineer: Gradle computes a *build cache key* for every cacheable task from its implementation hash plus the fingerprints of its inputs. `@Classpath` inputs are fingerprinted by content (jar entries hashed; paths, timestamps and the order of entries inside a jar ignored; the order of classpath entries is significant but deterministic). So a task whose only input is the main runtime classpath has a key that changes exactly when the runtime bytes change. The task's action is irrelevant; the key is the product.

```java
package io.joeyang.tracer.buildlogic;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Set;
import java.util.stream.Stream;
import org.gradle.testkit.runner.BuildResult;
import org.gradle.testkit.runner.GradleRunner;

/** Writes a throwaway Gradle project that can apply the convention plugins under test. */
final class GradleProject {
    static final String CATALOG = """
            [versions]
            junit = "6.1.3"
            [libraries]
            junit-bom = { module = "org.junit:junit-bom", version.ref = "junit" }
            junit-jupiter = { module = "org.junit.jupiter:junit-jupiter" }
            junit-platform-launcher = { module = "org.junit.platform:junit-platform-launcher" }
            """;

    final Path dir;
    final Path cacheDir;

    /** @param cacheDir shared local build cache; pass the same dir to two projects to test FROM-CACHE across locations */
    GradleProject(Path dir, Path cacheDir) throws IOException {
        this(dir, cacheDir, true);
    }

    /** @param writeScaffold false wraps an existing directory (see {@link #copyTo}) without overwriting its files */
    private GradleProject(Path dir, Path cacheDir, boolean writeScaffold) throws IOException {
        this.dir = dir;
        this.cacheDir = cacheDir;
        Files.createDirectories(dir);
        if (!writeScaffold) {
            return;
        }
        write("settings.gradle.kts", """
                dependencyResolutionManagement {
                    repositories { mavenCentral() }
                }
                buildCache {
                    local { directory = file("%s") }
                }
                rootProject.name = "sample"
                """.formatted(cacheDir.toString().replace("\\", "/")));
        write("gradle/libs.versions.toml", CATALOG);
        write("gradle.properties", "org.gradle.caching=true\n");
    }

    /** Each project gets its own local build cache, so test methods never see each other's FROM-CACHE hits. */
    GradleProject(Path dir) throws IOException {
        this(dir, dir.resolve(".build-cache"));
    }

    GradleProject write(String relative, String content) throws IOException {
        Path target = dir.resolve(relative);
        Files.createDirectories(target.getParent());
        Files.writeString(target, content);
        return this;
    }

    private static final Set<String> EXCLUDED_DIRS = Set.of("build", ".gradle", ".build-cache");

    /** Copies sources and build files (not build outputs, at any depth) to another directory sharing the same cache. */
    GradleProject copyTo(Path other) throws IOException {
        try (Stream<Path> paths = Files.walk(dir)) {
            for (Path p : paths.toList()) {
                Path rel = dir.relativize(p);
                boolean excluded = false;
                for (int i = 0; i < rel.getNameCount(); i++) {
                    if (EXCLUDED_DIRS.contains(rel.getName(i).toString())) {
                        excluded = true;
                        break;
                    }
                }
                if (excluded) {
                    continue;
                }
                Path target = other.resolve(rel);
                if (Files.isDirectory(p)) {
                    Files.createDirectories(target);
                } else {
                    Files.createDirectories(target.getParent());
                    Files.copy(p, target);
                }
            }
        }
        return new GradleProject(other, cacheDir, false);
    }

    BuildResult run(String... args) {
        return runner(args).build();
    }

    BuildResult runAndFail(String... args) {
        return runner(args).buildAndFail();
    }

    private GradleRunner runner(String... args) {
        return GradleRunner.create()
                .withProjectDir(dir.toFile())
                .withPluginClasspath()
                .withArguments(args)
                .forwardOutput();
    }
}
```

```java
package io.joeyang.tracer.buildlogic;

import java.io.File;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import org.gradle.api.DefaultTask;
import org.gradle.api.file.ConfigurableFileCollection;
import org.gradle.api.file.RegularFileProperty;
import org.gradle.api.tasks.CacheableTask;
import org.gradle.api.tasks.Classpath;
import org.gradle.api.tasks.OutputFile;
import org.gradle.api.tasks.TaskAction;

/**
 * A cacheable task whose only input is the main runtime classpath. Its build-cache key is therefore
 * a content hash of everything the application ships: own classes, project jars, third-party jars.
 * {@code @Classpath} normalisation ignores paths and timestamps (and entry order inside a jar) but not contents,
 * so a library bump changes the key and a comment-only edit (identical bytecode) does not. The order of classpath
 * entries themselves is significant, and deterministic for a given build. The marker file exists only so the
 * task has an output and can be cached; the key is the product.
 */
@CacheableTask
public abstract class FingerprintTask extends DefaultTask {

    @Classpath
    public abstract ConfigurableFileCollection getRuntimeClasspath();

    @OutputFile
    public abstract RegularFileProperty getMarker();

    @TaskAction
    public void write() throws IOException {
        List<String> names = getRuntimeClasspath().getFiles().stream()
                .map(File::getName)
                .sorted()
                .toList();
        Path out = getMarker().get().getAsFile().toPath();
        Files.write(out, names);
    }
}
```

```java
        SourceSetContainer sourceSets = project.getExtensions().getByType(SourceSetContainer.class);
        project.getTasks().register(FINGERPRINT_TASK, FingerprintTask.class, task -> {
            task.setGroup("verification");
            task.setDescription("Cacheable no-op whose build-cache key fingerprints the main runtime classpath");
            task.getRuntimeClasspath().from(
                    sourceSets.getByName(SourceSet.MAIN_SOURCE_SET_NAME).getRuntimeClasspath());
            task.getMarker().set(project.getLayout().getBuildDirectory().file("fingerprint/runtime-classpath.txt"));
        });
    }
```

```markdown
key: a content hash of the whole runtime classpath, path- and timestamp-independent. The key also folds
in `FingerprintTask`'s own implementation hash, so any commit that touches `build-logic` (or bumps the
Gradle wrapper) changes every module's `fingerprint` key — the tracer reports such commits as
build-logic culprits rather than runtime-input changes.

| edit | `compileJava` key of a consumer | `fingerprint` key of a consumer |
|---|---|---|
| method body in a dependency | unchanged (ABI normalisation) | changed |
| public method added in a dependency | changed | changed |
| comment-only edit, same line numbers | unchanged | unchanged (identical bytecode) |
| third-party version bump (implementation dep of a dependency) | unchanged | changed |

Read a key: `./gradlew :app:appA:fingerprint -Dorg.gradle.caching.debug=true --console=plain`.
```

```java
package io.joeyang.tracer.cli;

import java.nio.file.Path;
import java.time.Duration;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/** Scripted ProcessRunner: match commands by whole-token prefix, in registration order. */
final class FakeProcessRunner implements ProcessRunner {
    private final Map<String, Object> scripted = new LinkedHashMap<>(); // prefix → Result | ProcessException
    final List<List<String>> calls = new ArrayList<>();
    final List<Path> cwds = new ArrayList<>();
    final List<Duration> timeouts = new ArrayList<>();

    FakeProcessRunner on(String commandPrefix, int exit, String stdout, String stderr) {
        scripted.put(commandPrefix, new Result(exit, stdout, stderr));
        return this;
    }

    FakeProcessRunner failWith(String commandPrefix, ProcessException e) {
        scripted.put(commandPrefix, e);
        return this;
    }

    @Override
    public Result run(Path cwd, Duration timeout, List<String> command) throws ProcessException {
        List<String> commandCopy = List.copyOf(command);
        calls.add(commandCopy);
        cwds.add(cwd);
        timeouts.add(timeout);
        for (Map.Entry<String, Object> e : scripted.entrySet()) {
            if (matchesPrefix(commandCopy, e.getKey())) {
                if (e.getValue() instanceof ProcessException pe) {
                    throw pe;
                }
                return (Result) e.getValue();
            }
        }
        throw new AssertionError("unexpected command: " + String.join(" ", commandCopy));
    }

    boolean ran(String commandPrefix) {
        return calls.stream().anyMatch(c -> matchesPrefix(c, commandPrefix));
    }

    /** True when {@code command} starts with every token of {@code commandPrefix}, split on whitespace. */
    private static boolean matchesPrefix(List<String> command, String commandPrefix) {
        List<String> prefix = List.of(commandPrefix.trim().split("\\s+"));
        return command.size() >= prefix.size() && command.subList(0, prefix.size()).equals(prefix);
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.nio.file.Path;
import java.time.Duration;
import java.util.List;

/** Runs an external command. The single seam that lets tests inject failures without real processes. */
public interface ProcessRunner {

    /** Outcome of a process that started and finished. A non-zero exit is a Result, not an exception. */
    record Result(int exitCode, String stdout, String stderr) {
        public Result {
            stdout = stdout == null ? "" : stdout;
            stderr = stderr == null ? "" : stderr;
        }

        public boolean ok() {
            return exitCode == 0;
        }

        /** Best single line to show a human: first non-blank stderr line, else a stdout line mentioning failure, else the exit code. */
        public String firstErrorLine() {
            return stderr.lines().map(String::strip).filter(l -> !l.isEmpty()).findFirst()
                    .or(() -> stdout.lines().map(String::strip)
                            .filter(l -> l.contains("FAILURE") || l.contains("error") || l.contains("ERROR"))
                            .findFirst())
                    .orElse("exit code " + exitCode);
        }
    }

    /**
     * @throws ProcessException when the process could not be started, timed out, or the thread was interrupted
     */
    Result run(Path cwd, Duration timeout, List<String> command) throws ProcessException;
}
```

```java
package io.joeyang.tracer.cli;

import java.time.Duration;
import java.util.List;

/** The process could not run to completion (as opposed to running and failing). */
public final class ProcessException extends Exception {
    private final boolean startFailed;

    private ProcessException(String message, Throwable cause, boolean startFailed) {
        super(message, cause);
        this.startFailed = startFailed;
    }

    public static ProcessException cannotStart(List<String> command, Throwable cause) {
        return new ProcessException("cannot start '" + command.get(0) + "': " + cause.getMessage(), cause, true);
    }

    public static ProcessException timeout(List<String> command, Duration timeout) {
        return new ProcessException("'" + String.join(" ", command) + "' did not finish within " + timeout.toSeconds() + "s", null, false);
    }

    public static ProcessException interrupted(List<String> command) {
        return new ProcessException("interrupted while waiting for '" + command.get(0) + "'", null, false);
    }

    /** True when the process never launched (e.g. the binary is missing) — false when it ran but timed out or was interrupted. */
    public boolean startFailed() {
        return startFailed;
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Objects;

/**
 * A Gradle task's build-cache key and the fingerprints it was built from.
 *
 * @param taskPath e.g. {@code :app:appA:compileJava}
 * @param key the cache key hash as printed by Gradle
 * @param fileFingerprints input property name → (file path → content hash); e.g. {@code classpath → {/x/core.jar → ab12}}
 * @param valueFingerprints input property name → hash of a scalar input, e.g. {@code options.compilerArgs}
 * @param implementation the task implementation hash (changes when build logic changes)
 */
public record TaskKey(String taskPath, String key, Map<String, Map<String, String>> fileFingerprints,
                      Map<String, String> valueFingerprints, String implementation) {

    public TaskKey {
        Objects.requireNonNull(taskPath, "taskPath must not be null");
        Objects.requireNonNull(fileFingerprints, "fileFingerprints must not be null");
        Objects.requireNonNull(valueFingerprints, "valueFingerprints must not be null");
        if (key == null || key.isBlank()) {
            throw new IllegalArgumentException("cache key must not be blank for " + taskPath);
        }
        Map<String, Map<String, String>> files = new LinkedHashMap<>();
        fileFingerprints.forEach((property, byFile) -> files.put(property, Collections.unmodifiableMap(new LinkedHashMap<>(byFile))));
        fileFingerprints = Collections.unmodifiableMap(files);
        valueFingerprints = Collections.unmodifiableMap(new LinkedHashMap<>(valueFingerprints));
        implementation = implementation == null ? "" : implementation;
    }

    /** {@code 3f9c…3b} style abbreviation for tables. */
    public String shortKey() {
        return key.length() <= 7 ? key : key.substring(0, 4) + "…" + key.substring(key.length() - 2);
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Parses the lines Gradle prints with {@code -Dorg.gradle.caching.debug=true}. Lines belong to the task
 * announced by the preceding {@code > Task <path>} header (hence {@code --no-parallel}); a
 * {@code Build cache key for task '<path>' is <hash>} line, or a {@code Non-cacheable because ...} line,
 * closes the block. Any {@code Appending ...} line inside the target task's block that does not match one
 * of the shapes below is treated as unrecognised rather than silently dropped or mis-split (spec §9): a
 * Gradle upgrade that changes the format must fail loudly instead of producing a wrong, "clean" verdict.
 */
final class CacheDebugLog {
    private static final Pattern TASK_HEADER = Pattern.compile("^> Task (\\S+)");
    private static final Pattern IMPLEMENTATION = Pattern.compile("^Appending implementation to build cache key: (.+)$");
    private static final Pattern ADDITIONAL_IMPLEMENTATION =
            Pattern.compile("^Appending additional implementation to build cache key: (.+)$");
    private static final Pattern VALUE = Pattern.compile("^Appending input value fingerprint for '([^']+)' to build cache key: ([0-9a-f]+)$");
    private static final Pattern FILES = Pattern.compile("^Appending input file fingerprints for '([^']+)' to build cache key: [0-9a-f]+ - [A-Z_]+\\{(.*)\\}$");
    private static final Pattern OUTPUT_PROPERTY = Pattern.compile("^Appending output property name to build cache key: .+$");
    /**
     * A single already-isolated {@code <path>=<'normalized'|IGNORED> / <hash|DIR|MISSING>} entry, with the
     * path captured greedily so a path containing its own {@code '='} does not get cut at the wrong one:
     * the engine backtracks to the rightmost {@code '='} for which the rest of the pattern still matches
     * through end-of-string, which is always the real delimiter.
     */
    private static final Pattern ENTRY = Pattern.compile("^(/.+)=(?:'.*'|IGNORED) / (?:([0-9a-f]+)|DIR|MISSING)$");
    private static final Pattern KEY = Pattern.compile("^Build cache key for task '([^']+)' is ([0-9a-f]+)$");
    private static final Pattern NON_CACHEABLE = Pattern.compile("^Non-cacheable because (.+)$");

    private CacheDebugLog() {}

    static Optional<TaskKey> parse(String output, String taskPath) {
        Block block = blockFor(output, taskPath);
        if (block.key() == null) {
            return Optional.empty();
        }
        return Optional.of(new TaskKey(taskPath, block.key(), block.files(), block.values(), block.implementation()));
    }

    /** The reason Gradle printed instead of a key for {@code taskPath} (e.g. "Not worth caching [NOT_CACHEABLE]" for jar tasks). */
    static Optional<String> nonCacheableReason(String output, String taskPath) {
        return Optional.ofNullable(blockFor(output, taskPath).nonCacheableReason());
    }

    /**
     * Per-file fingerprints for {@code taskPath}, including a task that never prints a key (e.g. a jar
     * task). Exposed so tests can exercise entry parsing directly against properties, such as a {@code Jar}
     * task's {@code rootSpec$1}, that only ever appear on non-cacheable tasks.
     */
    static Map<String, Map<String, String>> fileFingerprintsFor(String output, String taskPath) {
        return blockFor(output, taskPath).files();
    }

    private record Block(String implementation, Map<String, Map<String, String>> files,
                          Map<String, String> values, String key, String nonCacheableReason) {}

    private static Block blockFor(String output, String taskPath) {
        List<String> implementations = new ArrayList<>();
        Map<String, String> values = new LinkedHashMap<>();
        Map<String, Map<String, String>> files = new LinkedHashMap<>();
        boolean inTarget = false;
        for (String raw : output.split("\\R")) {
            String line = raw.strip();
            Matcher header = TASK_HEADER.matcher(line);
            if (header.find()) {
                if (inTarget) {
                    return new Block(implementation(implementations), files, values, null, null);
                }
                inTarget = header.group(1).equals(taskPath);
                continue;
            }
            if (!inTarget) {
                continue;
            }
            Matcher m;
            if ((m = KEY.matcher(line)).matches()) {
                return new Block(implementation(implementations), files, values, m.group(2), null);
            }
            if ((m = NON_CACHEABLE.matcher(line)).matches()) {
                return new Block(implementation(implementations), files, values, null, m.group(1));
            }
            if ((m = IMPLEMENTATION.matcher(line)).matches()) {
                implementations.add(m.group(1));
            } else if ((m = ADDITIONAL_IMPLEMENTATION.matcher(line)).matches()) {
                // A task action / doLast block's own implementation hash; folded in alongside the task
                // class's so a build-logic change made only through a task action is still visible here.
                implementations.add(m.group(1));
            } else if ((m = VALUE.matcher(line)).matches()) {
                values.put(m.group(1), m.group(2));
            } else if ((m = FILES.matcher(line)).matches()) {
                files.put(m.group(1), entries(m.group(2), line));
            } else if (OUTPUT_PROPERTY.matcher(line).matches()) {
                // Does not affect the key material we track.
            } else if (line.startsWith("Appending ")) {
                throw unrecognised(line);
            }
        }
        return new Block(implementation(implementations), files, values, null, null);
    }

    private static String implementation(List<String> implementations) {
        return String.join(", ", implementations);
    }

    private static Map<String, String> entries(String body, String originalLine) {
        Map<String, String> out = new LinkedHashMap<>();
        if (body.isEmpty() || body.equals("EMPTY")) {
            return out;
        }
        // Split before parsing each entry so a "'" inside a normalized path can never merge two entries:
        // every entry boundary is ", " followed by the next entry's absolute path, which always starts with "/".
        for (String entry : body.split(", (?=/)")) {
            Matcher m = ENTRY.matcher(entry);
            if (!m.matches()) {
                throw unrecognised(originalLine);
            }
            String value = m.group(2) != null ? m.group(2) : entry.endsWith("DIR") ? "DIR" : "MISSING";
            out.put(m.group(1), value);
        }
        return out;
    }

    private static IllegalArgumentException unrecognised(String line) {
        return new IllegalArgumentException("unrecognised cache debug output: " + line);
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;
import java.util.Optional;
import java.util.regex.Pattern;

/** Runs the worktree's own {@code gradlew} with cache debugging on and parses the task's key out of the output. */
public final class GradleKeyProvider implements KeyProvider {
    private static final String WHAT_WENT_WRONG_HEADER = "* What went wrong:";
    /** A javac error line such as {@code AppA.java:11: error: ';' expected}, with or without a leading path. */
    private static final Pattern JAVAC_ERROR = Pattern.compile("^\\S+\\.java:\\d+: error: .+$");

    private final ProcessRunner runner;
    private final boolean offline;
    private final Duration timeout;

    public GradleKeyProvider(ProcessRunner runner, boolean offline, Duration timeout) {
        this.runner = Objects.requireNonNull(runner, "runner must not be null");
        this.offline = offline;
        this.timeout = Objects.requireNonNull(timeout, "timeout must not be null");
    }

    @Override
    public TaskKey keyFor(Path worktree, String taskPath) throws ProviderException {
        Path gradlew = worktree.resolve("gradlew");
        if (!Files.isExecutable(gradlew)) {
            throw new ProviderException("no executable gradlew in " + worktree + " (does this commit have the wrapper?)");
        }
        List<String> command = new ArrayList<>(List.of(gradlew.toString(), "--console=plain", "--no-parallel",
                "--build-cache", "-Dorg.gradle.caching.debug=true", taskPath));
        if (offline) {
            command.add("--offline");
        }
        ProcessRunner.Result result;
        try {
            result = runner.run(worktree, timeout, command);
        } catch (ProcessException e) {
            throw new ProviderException("gradle: " + e.getMessage(), e);
        }
        if (!result.ok()) {
            String cause = javacError(result).or(() -> whatWentWrong(result)).orElseGet(result::firstErrorLine);
            throw new ProviderException("gradle failed for " + taskPath + ": " + cause);
        }
        String output = result.stdout() + "\n" + result.stderr();
        try {
            return CacheDebugLog.parse(output, taskPath).orElseThrow(() -> new ProviderException(
                    CacheDebugLog.nonCacheableReason(output, taskPath)
                            .map(reason -> taskPath + " is not cacheable (" + reason + "), so it has no cache key; use compileJava or fingerprint")
                            .orElse("gradle printed no cache key for " + taskPath
                                    + " (unrecognised cache debug output, or the task did not print a key)")));
        } catch (IllegalArgumentException e) {
            throw new ProviderException("gradle debug output for " + taskPath + " could not be parsed: " + e.getMessage(), e);
        }
    }

    /** The first javac error line ({@code <file>.java:<line>: error: <message>}) anywhere in the output, if any. */
    private static Optional<String> javacError(ProcessRunner.Result result) {
        return (result.stdout() + "\n" + result.stderr()).lines()
                .map(String::strip)
                .filter(line -> JAVAC_ERROR.matcher(line).matches())
                .findFirst();
    }

    /**
     * The first non-blank line after Gradle's {@code * What went wrong:} header, joined with its first
     * continuation line (the line right after it, when that line is indented and non-blank) — Gradle often
     * puts the actual cause there rather than on the header's own first line, e.g. "Selection failed" /
     * "  Cannot locate tasks that match ...".
     */
    private static Optional<String> whatWentWrong(ProcessRunner.Result result) {
        List<String> lines = (result.stdout() + "\n" + result.stderr()).lines().toList();
        for (int i = 0; i < lines.size(); i++) {
            if (!lines.get(i).strip().equals(WHAT_WENT_WRONG_HEADER)) {
                continue;
            }
            for (int j = i + 1; j < lines.size(); j++) {
                String first = lines.get(j).strip();
                if (first.isEmpty()) {
                    continue;
                }
                if (j + 1 < lines.size()) {
                    String continuationRaw = lines.get(j + 1);
                    String continuation = continuationRaw.strip();
                    if (!continuation.isEmpty() && (continuationRaw.startsWith(" ") || continuationRaw.startsWith("\t"))) {
                        return Optional.of(first + ": " + continuation);
                    }
                }
                return Optional.of(first);
            }
        }
        return Optional.empty();
    }
}
```

```markdown
## Gradle oracle
`GradleKeyProvider` runs `<worktree>/gradlew --console=plain --no-parallel --build-cache -Dorg.gradle.caching.debug=true <task>`
(`--offline` when asked) and `CacheDebugLog` parses, per task block:
- `Appending implementation to build cache key: <class>@<hash>` → implementation hash (changes with build logic)
- `Appending input value fingerprint for '<property>' ...: <hash>` → scalar inputs such as `options.compilerArgs`
- `Appending input file fingerprints for '<property>' ...: <hash> - <NORMALIZATION>{<path>=<'normalized'|IGNORED> / <hash|DIR|MISSING>, ...}` → per-file hashes
  (a directory or a deleted file prints `DIR`/`MISSING` in place of a hash; project dependencies otherwise appear as class
  directories on the compile classpath and as jars on the runtime classpath, which later commits use to name a culprit like
  `core classes` under `compileJava` versus `core.jar` under `fingerprint`)
- `Build cache key for task '<path>' is <hash>` → the key, which closes the block
- `Non-cacheable because <reason>` (jar, installDist, …) also closes the block with no key; the provider reports the reason
  instead of a silent `clean`

`{...}` entry, anything a future Gradle version prints differently — fails parsing immediately with "unrecognised cache
debug output" naming the line, per spec §9, rather than silently dropping or mis-splitting it into a wrong key. An
UP-TO-DATE task prints the key line without input lines; the tracer always runs in a fresh worktree, so the inputs are
present whenever the key changed.

anywhere in the output, since Gradle's `* What went wrong:` header for a compile failure only says "Compilation failed;
see the compiler output below." — not the actual error. Failing that, it looks for the header and joins its first
non-blank line with the following line when that one is indented (e.g. "Selection failed" / "Cannot locate tasks that
match ..." for an unknown task, where the real cause is the indented continuation, not the header's own first line).

`ProviderException` naming the task and the offending line, instead of escaping uncaught. Computing *which* culprit
changed between two commits' `TaskKey`s, and the `./trace` revision-range walk that drives this provider, arrive in
later commits.
```

```java
package io.joeyang.tracer.cli;

import java.io.IOException;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.ArrayList;
import java.util.Collections;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Objects;
import java.util.Set;
import java.util.function.Function;
import java.util.regex.Pattern;

/**
 * The Bazel oracle: {@code bazel-diff generate-hashes} per worktree and {@code get-impacted-targets} per adjacent pair.
 * External Maven artifacts are hashed individually ({@code --fineGrainedHashExternalRepos=@maven}) so one library bump
 * impacts only its dependants. Every worktree gets its own Bazel output base, so the provider runs
 * {@code bazel clean --expunge} there afterwards to stop the server and free the disk.
 */
public final class BazelDiffProvider implements ImpactProvider {
    static final String FINE_GRAINED_REPOS = "@maven";
    private static final String HOW_TO_GET = " (run tools/fetch-bazel-diff.sh or set BAZEL_DIFF=/path/to/binary)";
    /** A Bazel label such as {@code //app/appA:appA}, {@code //lib}, or {@code @maven//:guava}. */
    private static final Pattern BAZEL_LABEL = Pattern.compile("^(@[^/]*)?//[^:]*(:[^:]+)?$");

    private final ProcessRunner runner;
    private final Path repo;
    private final boolean offline;
    private final Duration timeout;
    private final Path binary;
    private final PrintStream warnings;

    public BazelDiffProvider(ProcessRunner runner, Path repo, boolean offline, Duration timeout) {
        this(runner, repo, offline, timeout, defaultBinary(repo));
    }

    BazelDiffProvider(ProcessRunner runner, Path repo, boolean offline, Duration timeout, Path binary) {
        this(runner, repo, offline, timeout, binary, System.err);
    }

    BazelDiffProvider(ProcessRunner runner, Path repo, boolean offline, Duration timeout, Path binary, PrintStream warnings) {
        this.runner = Objects.requireNonNull(runner, "runner must not be null");
        this.repo = Objects.requireNonNull(repo, "repo must not be null");
        this.offline = offline;
        this.timeout = Objects.requireNonNull(timeout, "timeout must not be null");
        this.binary = Objects.requireNonNull(binary, "binary must not be null");
        this.warnings = Objects.requireNonNull(warnings, "warnings must not be null");
    }

    /** {@code $BAZEL_DIFF} if set, else the fetched copy under tools/bin, else whatever {@code bazel-diff} is on the PATH. */
    static Path defaultBinary(Path repo) {
        return defaultBinary(repo, System::getenv);
    }

    /** Same resolution, with the environment lookup injectable so tests do not depend on the real {@code $BAZEL_DIFF}. */
    static Path defaultBinary(Path repo, Function<String, String> getenv) {
        String env = getenv.apply("BAZEL_DIFF");
        if (env != null && !env.isBlank()) {
            return Path.of(env);
        }
        Path fetched = repo.resolve("tools/bin/bazel-diff");
        return Files.isExecutable(fetched) ? fetched : Path.of("bazel-diff");
    }

    @Override
    public Path hashes(Path worktree, Path output) throws ProviderException {
        List<String> command = new ArrayList<>(List.of(binary.toString(), "generate-hashes", "-w", worktree.toString(),
                "-b", "bazel", "--fineGrainedHashExternalRepos=" + FINE_GRAINED_REPOS));
        if (offline) {
            command.add("--bazelCommandOptions=--repository_disable_download");
        }
        command.add(output.toString());
        // A leftover file from a previous run must not be mistaken for this run's output if bazel-diff fails to write one.
        try {
            Files.deleteIfExists(output);
        } catch (IOException e) {
            throw new ProviderException("cannot remove the stale hashes file " + output + ": " + e.getMessage(), e);
        }
        boolean skipCleanup = false;
        try {
            ProcessRunner.Result result;
            try {
                result = run(repo, command);
            } catch (ProviderException e) {
                // Nothing to clean up only when bazel-diff never launched (e.g. the binary is missing): no Bazel server ran
                // in the worktree. A timeout or interruption may well have started one, so cleanup must still run then.
                if (e.getCause() instanceof ProcessException pe && pe.startFailed()) {
                    skipCleanup = true;
                }
                throw e;
            }
            if (!result.ok()) {
                throw new ProviderException("bazel-diff generate-hashes failed for " + worktree + ": " + bazelError(result));
            }
            if (!Files.isRegularFile(output)) {
                throw new ProviderException("bazel-diff produced no hashes file at " + output);
            }
            return output;
        } finally {
            if (!skipCleanup) {
                cleanUpServer(worktree);
            }
        }
    }

    @Override
    public Set<String> impactedTargets(Path previousHashes, Path currentHashes) throws ProviderException {
        Path impacted = currentHashes.resolveSibling(currentHashes.getFileName() + ".impacted.txt");
        List<String> command = List.of(binary.toString(), "get-impacted-targets", "-w", repo.toString(), "-b", "bazel",
                "--startingHashes", previousHashes.toString(), "--finalHashes", currentHashes.toString(), "-o", impacted.toString());
        ProcessRunner.Result result = run(repo, command);
        if (!result.ok()) {
            throw new ProviderException("bazel-diff get-impacted-targets failed for " + repo + ": " + bazelError(result));
        }
        List<String> lines;
        try {
            lines = Files.readAllLines(impacted);
        } catch (IOException e) {
            String reason = e.getMessage() == null || e.getMessage().equals(impacted.toString())
                    ? e.getClass().getSimpleName() : e.getMessage();
            throw new ProviderException("cannot read " + impacted + ": " + reason, e);
        }
        Set<String> targets = new LinkedHashSet<>();
        for (String rawLine : lines) {
            String line = rawLine.strip();
            if (line.isEmpty()) {
                continue;
            }
            if (!BAZEL_LABEL.matcher(line).matches()) {
                throw new ProviderException("bazel-diff wrote a line that is not a Bazel label ('" + line + "') in " + impacted);
            }
            targets.add(line);
        }
        return Collections.unmodifiableSet(targets);
    }

    private ProcessRunner.Result run(Path cwd, List<String> command) throws ProviderException {
        try {
            return runner.run(cwd, timeout, command);
        } catch (ProcessException e) {
            throw new ProviderException("bazel-diff: " + e.getMessage() + HOW_TO_GET, e);
        }
    }

    /**
     * The real Bazel error, not bazel-diff's own wrapper line ({@code "[Error] Bazel query failed, exit code N: ..."}),
     * which never names the actual cause. Prefers a line mentioning "download is disabled" (a cold, offline output base),
     * else the first line Bazel itself prefixes with {@code ERROR:}, else the generic {@link ProcessRunner.Result#firstErrorLine()}.
     */
    private static String bazelError(ProcessRunner.Result result) {
        List<String> lines = (result.stdout() + "\n" + result.stderr()).lines().map(String::strip).filter(l -> !l.isEmpty()).toList();
        return lines.stream().filter(l -> l.contains("download is disabled")).findFirst()
                .or(() -> lines.stream().filter(l -> l.startsWith("ERROR:")).findFirst())
                .orElseGet(result::firstErrorLine);
    }

    private void cleanUpServer(Path worktree) {
        try {
            ProcessRunner.Result result = runner.run(worktree, timeout, List.of("bazel", "clean", "--expunge"));
            if (!result.ok()) {
                warnings.println("trace: bazel clean --expunge failed in " + worktree + ": " + result.firstErrorLine());
            }
        } catch (ProcessException e) {
            warnings.println("trace: could not clean the Bazel output base of " + worktree + " (" + e.getMessage() + ")");
        }
    }
}
```

```java
    private static ProcessRunner realGit() {

            Process process;
            try {
                process = new ProcessBuilder(command).directory(cwd.toFile()).start();
            } catch (IOException e) {
                throw ProcessException.cannotStart(command, e);
            }
            String out, err;
            try {
                out = new String(process.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
                err = new String(process.getErrorStream().readAllBytes(), StandardCharsets.UTF_8);
                if (!process.waitFor(timeout.toSeconds(), TimeUnit.SECONDS)) {
                    process.destroyForcibly();
                    throw ProcessException.timeout(command, timeout);
                }
            } catch (IOException e) {
                throw ProcessException.cannotStart(command, e);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                throw ProcessException.interrupted(command);
            }
            return new ProcessRunner.Result(process.exitValue(), out, err);
        };
    }

    private static ProcessRunner.Result run(ProcessRunner git, Path cwd, String... command) throws ProcessException {
        ProcessRunner.Result r = git.run(cwd, Duration.ofSeconds(30), List.of(command));
        if (!r.ok()) {
```

```java
package io.joeyang.tracer.cli;

import java.nio.file.Path;
import java.time.Duration;
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;

/** Turns {@code --from/--to} into an ordered commit list: the base commit first, then every first-parent commit in from..to. */
public final class RevisionRange {
    private static final Duration TIMEOUT = Duration.ofSeconds(30);
    // %P is every parent sha, space-separated; for a root commit it is empty. Only the first token (the first
    // parent) matters here, since the walk follows --first-parent.
    private static final String FORMAT = "--format=%H%x1f%P%x1f%s";

    private final ProcessRunner git;
    private final Path repo;

    public RevisionRange(ProcessRunner git, Path repo) {
        this.git = Objects.requireNonNull(git, "git must not be null");
        this.repo = Objects.requireNonNull(repo, "repo must not be null");
    }

    public List<Commit> resolve(String from, String to) throws UsageException, ProviderException {
        String fromSha = revParse(from);
        String toSha = revParse(to);
        List<Commit> commits = new ArrayList<>();
        ProcessRunner.Result base = run("git", "log", "-1", FORMAT, fromSha);
        if (!base.ok()) {
            throw new ProviderException("git log failed for '" + fromSha + "': " + base.firstErrorLine());
        }
        commits.add(parse(base.stdout().strip()));
        ProcessRunner.Result log = run("git", "log", "--reverse", "--first-parent", FORMAT, fromSha + ".." + toSha);
        if (!log.ok()) {
            throw new ProviderException("git log failed: " + log.firstErrorLine());
        }
        // 'from' must be an ancestor of 'to' on its first-parent line: a side-branch commit merged into 'to' (or
        // any other commit not actually on that line) would otherwise pair up with an unrelated predecessor and
        // silently compare the wrong build inputs.
        String previousSha = fromSha;
        // split("\n") only: String.lines() also treats a bare \r as a line terminator, and %s keeps whatever
        // characters the subject has, including one, so a bare \r would otherwise split one row into two.
        for (String line : log.stdout().split("\n", -1)) {
            if (line.isBlank()) {
                continue;
            }
            Row row = parseRow(line);
            if (!row.firstParent().equals(previousSha)) {
                throw new UsageException("commit '" + row.commit().sha() + "' is not a first-parent descendant of '"
                        + previousSha + "'; 'from' must be an ancestor of 'to' on its first-parent history");
            }
            commits.add(row.commit());
            previousSha = row.commit().sha();
        }
        if (commits.size() == 1) {
            throw new UsageException("no commits between '" + from + "' and '" + to + "'");
        }
        return commits;
    }

    private String revParse(String rev) throws UsageException, ProviderException {
        ProcessRunner.Result r = run("git", "rev-parse", "--verify", "--quiet", rev + "^{commit}");
        // Under --quiet, real git exits 1 (with no stderr) for a revision it simply cannot resolve. Any other
        // non-zero exit (128 for "fatal: not a git repository", a detached/broken worktree, ...) is a tool
        // failure unrelated to whether the revision itself is valid.
        if (r.exitCode() == 1) {
            throw new UsageException("unknown revision '" + rev + "'");
        }
        if (!r.ok()) {
            throw new ProviderException("git rev-parse failed for '" + rev + "': " + r.firstErrorLine());
        }
        return r.stdout().strip();
    }

    private ProcessRunner.Result run(String... command) throws ProviderException {
        try {
            return git.run(repo, TIMEOUT, List.of(command));
        } catch (ProcessException e) {
            throw new ProviderException(e.getMessage(), e);
        }
    }

    /** One parsed {@code git log} row: the commit plus its first parent, used only to validate the first-parent chain. */
    private record Row(Commit commit, String firstParent) {}

    // Amendment (code review): Commit's compact constructor throws an unchecked IllegalArgumentException for a sha
    // that isn't 40 lowercase hex chars. The CLI's walk (Task 13) catches only UsageException and ProviderException,
    // so a SHA-256 repo or a stray `git log` output line would otherwise escape as a stack trace with exit code 1
    // (the usage-error code) instead of the ProviderException exit code. Translate it here, naming the bad line.
    private static Commit parse(String line) throws ProviderException {
        return parseRow(line).commit();
    }

    private static Row parseRow(String line) throws ProviderException {
        String[] parts = line.split("\u001f", 3);
        if (parts.length < 3) {
            throw new ProviderException("unexpected git log line: '" + line + "': expected sha, parents, subject");
        }
        String firstParent = parts[1].isBlank() ? "" : parts[1].split(" ", 2)[0];
        try {
            return new Row(new Commit(parts[0], parts[2]), firstParent);
        } catch (IllegalArgumentException e) {
            throw new ProviderException("unexpected git log line: '" + line + "': " + e.getMessage(), e);
        }
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.io.IOException;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Objects;
import java.util.Set;
import java.util.function.Consumer;
import java.util.regex.Pattern;
import java.util.stream.Stream;

/**
 * Materialises commits as detached git worktrees under a scratch root and removes them again.
 * Removal happens on {@link #close()} and from a JVM shutdown hook, so Ctrl-C leaves nothing behind, unless
 * {@code keep} is set.
 */
public final class WorktreePool implements AutoCloseable {
    private static final Duration TIMEOUT = Duration.ofMinutes(2);
    /**
     * A worktree directory's own name: {@code wt-} plus a 7-hex-char short sha, nothing else.
     * Package-private: {@link KeyComparator} reuses this to strip the worktree root off a culprit path before
     * naming it, since the two commit's worktrees otherwise differ by this prefix. If this naming convention ever
     * changes, {@link KeyComparator}'s stripping must change with it. (Amendment, Task 10 quality review.)
     */
    static final Pattern WT_DIR_NAME = Pattern.compile("wt-[0-9a-f]{7}");

    private final ProcessRunner git;
    private final Path repo;
    private final Path root;
    private final boolean keep;
    private final PrintStream warnings;
    private final Set<Path> created = Collections.synchronizedSet(new LinkedHashSet<>());
    /** Null when {@code keep} is true: Ctrl-C must leave kept worktrees exactly where {@code --keep-worktrees} put them. */
    private final Thread shutdownHook;

    public WorktreePool(ProcessRunner git, Path repo, Path root, boolean keep) throws ProviderException {
        this(git, repo, root, keep, System.err, Runtime.getRuntime()::addShutdownHook);
    }

    /** Package-private seam: lets tests capture warnings and observe hook registration without touching real I/O or the JVM hook list. */
    WorktreePool(ProcessRunner git, Path repo, Path root, boolean keep, PrintStream warnings, Consumer<Thread> hookRegistrar)
            throws ProviderException {
        this.git = Objects.requireNonNull(git, "git must not be null");
        this.repo = Objects.requireNonNull(repo, "repo must not be null");
        this.root = Objects.requireNonNull(root, "root must not be null");
        this.keep = keep;
        this.warnings = Objects.requireNonNull(warnings, "warnings must not be null");
        Objects.requireNonNull(hookRegistrar, "hookRegistrar must not be null");
        // Sweep before prune: 'git worktree prune' only forgets a worktree whose directory is already missing.
        // After --keep-worktrees or a killed run the directory is still there, so pruning first is a no-op; the
        // sweep then deletes the directory out from under git, leaving a dangling registration that makes the
        // next 'worktree add' of the same path fail with "is a missing but already registered worktree".
        sweepStaleDirectories();
        ProcessRunner.Result pruneResult = run("git", "worktree", "prune");
        if (!pruneResult.ok()) {
            throw new ProviderException("git worktree prune failed: " + pruneResult.firstErrorLine());
        }
        try {
            Files.createDirectories(root);
        } catch (IOException e) {
            throw new ProviderException("cannot create worktree root " + root + ": " + e.getMessage(), e);
        }
        this.shutdownHook = keep ? null : new Thread(this::removeAll, "worktree-cleanup");
        if (shutdownHook != null) {
            hookRegistrar.accept(shutdownHook);
        }
    }

    /** A killed run (or a kept one) leaves {@code wt-*} directories behind; delete them before prune forgets them. */
    private void sweepStaleDirectories() {
        if (!Files.isDirectory(root)) {
            return;
        }
        try (Stream<Path> entries = Files.list(root)) {
            List<Path> stale = entries.filter(Files::isDirectory)
                    .filter(d -> WT_DIR_NAME.matcher(d.getFileName().toString()).matches())
                    .toList();
            stale.forEach(WorktreePool::deleteRecursively);
            if (!stale.isEmpty()) {
                warnings.println("trace: removed " + stale.size() + " stale worktree dir(s) under " + root);
            }
        } catch (IOException ignored) {
            // best effort; checkout() deletes a same-named leftover anyway
        }
    }

    public Path checkout(Commit commit) throws ProviderException {
        Path dir = root.resolve("wt-" + commit.shortSha());
        if (Files.exists(dir)) {
            // Unregister before deleting: if this directory is still a registered worktree (left behind between
            // the constructor's one-time sweep and this call), deleting it without 'git worktree remove' first
            // would leave git thinking it still exists, and the 'add' below would fail as "missing but already
            // registered". Best effort: if it was never registered, this fails harmlessly and is ignored.
            try {
                git.run(repo, TIMEOUT, List.of("git", "worktree", "remove", "--force", dir.toString()));
            } catch (ProcessException ignored) {
                // see above
            }
            deleteRecursively(dir);
        }
        ProcessRunner.Result r = run("git", "worktree", "add", "--detach", dir.toString(), commit.sha());
        if (!r.ok()) {
            throw new ProviderException("git worktree add failed for " + commit.shortSha() + ": " + r.firstErrorLine());
        }
        created.add(dir);
        return dir;
    }

    /** Removes one worktree early to bound disk usage during long ranges. */
    public void release(Path dir) {
        if (!created.contains(dir)) {
            throw new IllegalArgumentException("not a tracked worktree: " + dir);
        }
        remove(dir);
    }

    @Override
    public void close() {
        if (!keep) {
            removeAll();
        }
        if (shutdownHook != null) {
            try {
                Runtime.getRuntime().removeShutdownHook(shutdownHook);
            } catch (IllegalStateException alreadyShuttingDown) {
                // the hook itself is running; nothing to do
            }
        }
    }

    private void removeAll() {
        List<Path> snapshot;
        synchronized (created) {
            snapshot = new ArrayList<>(created);
        }
        for (Path dir : snapshot) {
            remove(dir);
        }
    }

    private void remove(Path dir) {
        try {
            ProcessRunner.Result r = git.run(repo, TIMEOUT, List.of("git", "worktree", "remove", "--force", dir.toString()));
            if (!r.ok()) {
                warnings.println("trace: could not remove worktree " + dir + " (" + r.firstErrorLine() + ")");
            }
        } catch (ProcessException e) {
            warnings.println("trace: could not remove worktree " + dir + " (" + e.getMessage() + ")");
        }
        deleteRecursively(dir);
        created.remove(dir);
    }

    private ProcessRunner.Result run(String... command) throws ProviderException {
        try {
            return git.run(repo, TIMEOUT, List.of(command));
        } catch (ProcessException e) {
            throw new ProviderException(e.getMessage(), e);
        }
    }

    private static void deleteRecursively(Path dir) {
        if (!Files.exists(dir)) {
            return;
        }
        try (Stream<Path> paths = Files.walk(dir)) {
            paths.sorted(Comparator.reverseOrder()).forEach(p -> {
                try {
                    Files.deleteIfExists(p);
                } catch (IOException ignored) {
                    // best effort; git worktree remove already did the real work
                }
            });
        } catch (IOException ignored) {
            // best effort
        }
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Objects;
import java.util.Optional;
import java.util.Set;
import java.util.TreeSet;
import java.util.stream.Collectors;

/** Pure logic: turns two adjacent keys into a verdict and a short list of culprits. */
public final class KeyComparator {
    static final int MAX_CULPRITS = 4;

    private KeyComparator() {}

    /**
     * @param previous the last successfully obtained key before this commit; empty for the base commit
     * @param current the key at this commit; empty when the build failed
     * @param error the failure reason when {@code current} is empty
     */
    public static Verdict verdict(Commit commit, Optional<TaskKey> previous, Optional<TaskKey> current,
                                  Optional<String> error, BazelStatus bazel) {
        Objects.requireNonNull(commit, "commit must not be null");
        Objects.requireNonNull(previous, "previous must not be null");
        Objects.requireNonNull(current, "current must not be null");
        Objects.requireNonNull(error, "error must not be null");
        Objects.requireNonNull(bazel, "bazel must not be null");
        if (current.isEmpty()) {
            return new Verdict(commit, Status.BUILD_FAILED, Optional.empty(), bazel, List.of(),
                    Optional.of(error.orElse("no cache key obtained")));
        }
        if (previous.isEmpty()) {
            return new Verdict(commit, Status.BASE, current, bazel, List.of(), Optional.empty());
        }
        if (previous.get().key().equals(current.get().key())) {
            return new Verdict(commit, Status.CLEAN, current, bazel, List.of(), Optional.empty());
        }
        return new Verdict(commit, Status.CHANGED, current, bazel, culprits(previous.get(), current.get()), Optional.empty());
    }

    static List<String> culprits(TaskKey before, TaskKey after) {
        // "build logic" goes first unconditionally, ahead of file/value names, so it is never pushed past the
        // MAX_CULPRITS cap and hidden behind "+N more": a build-logic change is usually the most actionable one.
        List<String> names = new ArrayList<>();
        if (!before.implementation().equals(after.implementation())) {
            names.add("build logic");
        }
        Set<String> rest = new LinkedHashSet<>();
        for (String property : union(before.fileFingerprints().keySet(), after.fileFingerprints().keySet())) {
            Map<String, String> a = before.fileFingerprints().getOrDefault(property, Map.of());
            Map<String, String> b = after.fileFingerprints().getOrDefault(property, Map.of());
            Map<String, String> aByName = byDisplayName(a);
            Map<String, String> bByName = byDisplayName(b);
            for (String name : union(aByName.keySet(), bByName.keySet())) {
                if (!Objects.equals(aByName.get(name), bByName.get(name))) {
                    rest.add(name);
                }
            }
        }
        for (String property : union(before.valueFingerprints().keySet(), after.valueFingerprints().keySet())) {
            if (!Objects.equals(before.valueFingerprints().get(property), after.valueFingerprints().get(property))) {
                rest.add(property);
            }
        }
        names.addAll(rest);
        if (names.isEmpty()) {
            return List.of("inputs changed (no fingerprint detail)");
        }
        if (names.size() <= MAX_CULPRITS + 1) {
            return names;
        }
        List<String> capped = new ArrayList<>(names.subList(0, MAX_CULPRITS));
        capped.add("+" + (names.size() - MAX_CULPRITS) + " more");
        return capped;
    }

    /**
     * Paths differ between worktrees, so compare by a location-independent display name. Several paths can share a
     * name (every class file under {@code core/build/classes/...} is "core classes"), so the value is the sorted
     * join of all their hashes: it changes if any one of them changes.
     */
    private static Map<String, String> byDisplayName(Map<String, String> byPath) {
        Map<String, List<String>> grouped = new LinkedHashMap<>();
        byPath.forEach((path, hash) -> grouped.computeIfAbsent(displayName(path), k -> new ArrayList<>()).add(hash));
        Map<String, String> out = new LinkedHashMap<>();
        grouped.forEach((name, hashes) -> out.put(name, hashes.stream().sorted().collect(Collectors.joining("+"))));
        return out;
    }

    /**
     * {@code .../core/build/libs/core.jar → core.jar}; {@code .../app/appA/src/main/java/X.java → appA/src/main/java/X.java};
     * {@code .../appA/build/classes/java/main/... → appA classes}; {@code .../appA/build/resources/main/... → appA resources};
     * {@code ~/.gradle/caches/modules-2/files-2.1/com.google.code.gson/gson/2.11.0/<sha>/gson-2.11.0.jar → com.google.code.gson:gson}
     * (so a version bump is one culprit, not a removed plus an added jar).
     *
     * <p>The worktree root (e.g. {@code .../wt-a1b2c3d/}) is stripped first, so a root path that itself happens to
     * contain {@code /src/} (a user's checkout under {@code ~/src/...}) never leaks into the name, and two commits'
     * worktrees — which differ only by that prefix — compare equal. What remains is matched against the module's
     * own {@code /src/}, using its first occurrence so a resource that happens to be nested under another
     * {@code src} directory (e.g. {@code core/src/main/resources/src/x.txt}) is still named relative to its real
     * module ({@code core/src/...}), not the inner one.
     */
    static String displayName(String path) {
        String p = stripWorktreeRoot(path.replace('\\', '/'));
        int classes = p.lastIndexOf("/build/classes/");
        if (classes >= 0) {
            return lastSegmentBefore(p, classes) + " classes";
        }
        int resources = p.lastIndexOf("/build/resources/");
        if (resources >= 0) {
            return lastSegmentBefore(p, resources) + " resources";
        }
        int cache = p.indexOf("/modules-2/files-2.1/");
        if (cache >= 0) {
            String[] parts = p.substring(cache + "/modules-2/files-2.1/".length()).split("/");
            if (parts.length >= 2) {
                return parts[0] + ":" + parts[1];
            }
        }
        int src = p.indexOf("/src/");
        if (src >= 0) {
            String module = lastSegmentBefore(p, src);
            return module.isEmpty() ? p.substring(src + 1) : module + p.substring(src);
        }
        return p.substring(p.lastIndexOf('/') + 1);
    }

    /**
     * Strips everything up to and including the last {@code wt-<sha7>} path segment, i.e. {@link WorktreePool}'s
     * worktree directory naming ({@link WorktreePool#WT_DIR_NAME}); a path with no such segment is returned as is.
     * The result keeps its leading slash so the rest of {@link #displayName} can treat it uniformly.
     */
    private static String stripWorktreeRoot(String p) {
        String[] segments = p.split("/");
        for (int i = segments.length - 1; i >= 0; i--) {
            if (WorktreePool.WT_DIR_NAME.matcher(segments[i]).matches()) {
                return "/" + String.join("/", Arrays.asList(segments).subList(i + 1, segments.length));
            }
        }
        return p;
    }

    private static String lastSegmentBefore(String p, int index) {
        int from = p.lastIndexOf('/', index - 1);
        return from < 0 ? "" : p.substring(from + 1, index);
    }

    private static Set<String> union(Set<String> a, Set<String> b) {
        Set<String> u = new TreeSet<>(a);
        u.addAll(b);
        return u;
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.util.List;
import java.util.stream.Collectors;

/** Fixed-width table for humans and TSV for scripts. */
public final class TableRenderer {
    static final int SUBJECT_WIDTH = 36;

    private TableRenderer() {}

    /** @param bazelTarget null when the bazel column was disabled */
    public static String render(String taskPath, String bazelTarget, List<Verdict> rows) {
        StringBuilder sb = new StringBuilder();
        int commits = Math.max(0, rows.size() - 1);
        sb.append("Tracing inputs of ").append(taskPath).append(" (gradle)");
        if (bazelTarget != null) {
            sb.append(" and ").append(bazelTarget).append(" (bazel-diff)");
        }
        sb.append(" over ").append(commits).append(commits == 1 ? " commit" : " commits").append("\n\n");
        sb.append(pad("commit", 9)).append(pad("subject", SUBJECT_WIDTH + 1)).append(pad("gradle key", 12))
                .append(pad("bazel-diff", 12)).append(pad("verdict", 14)).append("culprit\n");
        for (Verdict v : rows) {
            sb.append(pad(v.commit().shortSha(), 9))
                    .append(pad(truncate(v.commit().subject(), SUBJECT_WIDTH), SUBJECT_WIDTH + 1))
                    .append(pad(v.key().map(TaskKey::shortKey).orElse("-"), 12))
                    .append(pad(v.bazel().label(), 12))
                    .append(pad(v.status().label(), 14))
                    .append(culpritColumn(v)).append("\n");
        }
        sb.append("\n").append(summary(taskPath, rows)).append("\n");
        return sb.toString();
    }

    public static String renderTsv(List<Verdict> rows) {
        return rows.stream().map(v -> String.join("\t",
                v.commit().sha(), v.commit().subject(), v.key().map(TaskKey::key).orElse(""),
                v.bazel().label(), v.status().label(),
                v.status() == Status.BUILD_FAILED ? v.error().orElse("") : String.join(", ", v.culprits())))
                .collect(Collectors.joining("\n", "", "\n"));
    }

    private static String culpritColumn(Verdict v) {
        if (v.status() == Status.BUILD_FAILED) {
            return v.error().orElse("");
        }
        String culprits = String.join(", ", v.culprits());
        if (v.bazelDisagrees()) {
            return culprits.isEmpty() ? "bazel≠gradle" : culprits + " (bazel≠gradle)";
        }
        return culprits;
    }

    private static String summary(String taskPath, List<Verdict> rows) {
        String app = appName(taskPath);
        String kind = taskPath.endsWith(":fingerprint") ? "runtime inputs" : taskPath.endsWith(":compileJava") ? "compile inputs" : "inputs";
        long changed = rows.stream().filter(v -> v.status() == Status.CHANGED).count();
        long failed = rows.stream().filter(v -> v.status() == Status.BUILD_FAILED).count();
        int commits = Math.max(0, rows.size() - 1);
        StringBuilder sb = new StringBuilder();
        if (changed == 0) {
            sb.append("No commit changed ").append(kind).append(" of ").append(app).append(".");
        } else {
            String first = rows.stream().filter(v -> v.status() == Status.CHANGED).findFirst().orElseThrow().commit().shortSha();
            sb.append(changed).append(" of ").append(commits).append(commits == 1 ? " commit" : " commits")
                    .append(" changed ").append(kind).append(" of ").append(app).append(". First: ").append(first).append(".");
        }
        if (failed > 0) {
            sb.append(" ").append(failed).append(failed == 1 ? " commit" : " commits").append(" could not be built.");
        }
        return sb.toString();
    }

    /** {@code :app:appA:compileJava → appA}. */
    static String appName(String taskPath) {
        String[] parts = taskPath.split(":");
        return parts.length >= 2 ? parts[parts.length - 2] : taskPath;
    }

    private static String truncate(String s, int width) {
        return s.length() <= width ? s : s.substring(0, width - 1) + "…";
    }

    private static String pad(String s, int width) {
        return s.length() >= width ? s + " " : s + " ".repeat(width - s.length());
    }
}
```

```java
package io.joeyang.tracer.cli;

import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.nio.file.Path;
import java.time.Duration;
import java.util.List;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.TimeUnit;

/** Runs commands with {@link ProcessBuilder}; streams are drained concurrently so large output cannot deadlock. */
public final class DefaultProcessRunner implements ProcessRunner {

    @Override
    public Result run(Path cwd, Duration timeout, List<String> command) throws ProcessException {
        Process process;
        try {
            process = new ProcessBuilder(command).directory(cwd.toFile()).start();
        } catch (IOException e) {
            throw ProcessException.cannotStart(command, e);
        }
        CompletableFuture<String> stdout = drain(process.getInputStream());
        CompletableFuture<String> stderr = drain(process.getErrorStream());
        boolean finished;
        try {
            finished = process.waitFor(timeout.toMillis(), TimeUnit.MILLISECONDS);
        } catch (InterruptedException e) {
            killTree(process);
            Thread.currentThread().interrupt();
            throw ProcessException.interrupted(command);
        }
        if (!finished) {
            killTree(process);
            throw ProcessException.timeout(command, timeout);
        }
        return new Result(process.exitValue(), stdout.join(), stderr.join());
    }

    private static void killTree(Process process) {
        process.descendants().forEach(ProcessHandle::destroyForcibly);
        process.destroyForcibly();
    }

    private static CompletableFuture<String> drain(InputStream in) {
        return CompletableFuture.supplyAsync(() -> {
            try (in) {
                return new String(in.readAllBytes(), StandardCharsets.UTF_8);
            } catch (IOException e) {
                return "";
            }
        });
    }
}
```

```java
    static final String USAGE = """
            usage: trace <app> --from <rev> --to <rev> [--task <name>] [--no-bazel] [--offline] [--keep-worktrees]
                                                        [--tsv | --tsv-out <file>] [--timeout-minutes <n>]

              <app>            appA | appB | appC   (maps to :app:<app>:<task> and //app/<app>:<app>)
              --task           Gradle task whose cache key is compared; default compileJava, alternative fingerprint
              --no-bazel       skip the bazel-diff column
              --offline        pass --offline to gradle; forbid repository downloads in bazel
              --keep-worktrees leave the checked-out worktrees and hash files in place for inspection
              --tsv            machine-readable output only (sha, subject, key, bazel, verdict, culprits)
              --tsv-out <file> print the table and also write the TSV to <file>
              --timeout-minutes per external command, default 10

            exit codes: 0 no change, 1 usage error, 2 a tool failed, 3 at least one CHANGED
            """;

    /** Parsed command line. */
    record Options(String app, String from, String to, String at, String task, boolean bazel, boolean offline,
                   boolean keepWorktrees, boolean tsv, Path tsvOut, Duration timeout) {

        static Options parse(String[] args) throws UsageException {
            if (args.length == 0) {
                throw new UsageException("missing <app>");
            }
            String app = args[0];
            if (app.startsWith("--")) {
                throw new UsageException("first argument must be the app name, got '" + app + "'");
            }
            String from = null, to = null, at = null, task = "compileJava";
            boolean bazel = true, offline = false, keep = false, tsv = false;
            Path tsvOut = null;
            Duration timeout = Duration.ofMinutes(10);
            for (int i = 1; i < args.length; i++) {
                String flag = args[i];
                switch (flag) {
                    case "--no-bazel" -> bazel = false;
                    case "--offline" -> offline = true;
                    case "--keep-worktrees" -> keep = true;
                    case "--tsv" -> tsv = true;
                    case "--from", "--to", "--at", "--task", "--tsv-out", "--timeout-minutes" -> {
                        if (i + 1 >= args.length) {
                            throw new UsageException(flag + " needs a value");
                        }
                        String value = args[++i];
                        switch (flag) {
                            case "--from" -> from = value;
                            case "--to" -> to = value;
                            case "--at" -> at = value;
                            case "--task" -> task = value;
                            case "--tsv-out" -> tsvOut = Path.of(value);
                            default -> timeout = parseMinutes(value);
                        }
                    }
                    default -> throw new UsageException("unknown option '" + flag + "'");
                }
            }
            if (at != null && (from != null || to != null)) {
                throw new UsageException("use either --at or --from/--to, not both");
            }
            if (at == null && (from == null || to == null)) {
                throw new UsageException("--from and --to are both required (or use --at)");
            }
            return new Options(app, from, to, at, task, bazel, offline, keep, tsv, tsvOut, timeout);
        }

        private static Duration parseMinutes(String value) throws UsageException {
            try {
                return Duration.ofMinutes(Long.parseLong(value));
            } catch (NumberFormatException e) {
                throw new UsageException("--timeout-minutes needs a whole number, got '" + value + "'");
            }
        }

        String taskPath() {
            return ":app:" + app + ":" + task;
        }

        String bazelTarget() {
            return "//app/" + app + ":" + app;
        }
    }

    private Cli() {}

    static int usage(PrintStream err, String problem) {
        err.println("trace: " + problem);
        err.print(USAGE);
        return EXIT_USAGE;
    }

        try {
            Options.parse(args);
        } catch (UsageException e) {
            System.exit(usage(System.err, e.getMessage()));
            return;
        }
        System.err.println("trace: options accepted; the range walk arrives in the next task");
        System.exit(EXIT_TOOL_FAILURE);
    }
```

```java
            if (at != null && (from != null || to != null)) {
                throw new UsageException("use either --at or --from/--to, not both");
            }
            if (at == null && (from == null || to == null)) {
                throw new UsageException("--from and --to are both required (or use --at)");
            }
            return new Options(app, from, to, at, task, bazel, offline, keep, tsv, tsvOut, timeout);
        }

        private static Duration parseMinutes(String value) throws UsageException {
            try {
                return Duration.ofMinutes(Long.parseLong(value));
            } catch (NumberFormatException e) {
                throw new UsageException("--timeout-minutes needs a whole number, got '" + value + "'");
            }
        }

        String taskPath() {
            return ":app:" + app + ":" + task;
        }

        String bazelTarget() {
            return "//app/" + app + ":" + app;
        }
    }

    private final ProcessRunner runner;
    private final Path repo;
    private final Path scratch;
    private final KeyProvider keys;
    private final ImpactProvider impacts; // null when --no-bazel

    Cli(ProcessRunner runner, Path repo, Path scratch, KeyProvider keys, ImpactProvider impacts) {
        this.runner = runner;
        this.repo = repo;
        this.scratch = scratch;
        this.keys = keys;
        this.impacts = impacts;
    }

    public static void main(String[] args) {
        Options options;
        try {
            options = Options.parse(args);
        } catch (UsageException e) {
            System.exit(usage(System.err, e.getMessage()));
            return;
        }
        ProcessRunner runner = new DefaultProcessRunner();
        Path repo = Path.of("").toAbsolutePath();
        KeyProvider keys = new GradleKeyProvider(runner, options.offline(), options.timeout());
        ImpactProvider impacts = options.bazel() ? new BazelDiffProvider(runner, repo, options.offline(), options.timeout()) : null;
        System.exit(new Cli(runner, repo, DEFAULT_SCRATCH, keys, impacts).run(options, System.out, System.err));
    }

    static int usage(PrintStream err, String problem) {
        err.println("trace: " + problem);
        err.print(USAGE);
        return EXIT_USAGE;
    }

    int run(Options o, PrintStream out, PrintStream err) {
        try {
            if (!Files.isDirectory(repo.resolve("app").resolve(o.app()))) {
                throw new UsageException("unknown app '" + o.app() + "': expected a directory app/" + o.app());
            }
            return o.at() != null ? at(o, out) : range(o, out, err);
        } catch (UsageException e) {
            return usage(err, e.getMessage());
        } catch (ProviderException e) {
            err.println("trace: " + e.getMessage());
            return EXIT_TOOL_FAILURE;
        }
    }

    private int range(Options o, PrintStream out, PrintStream err) throws UsageException, ProviderException {
        List<Commit> commits = new RevisionRange(runner, repo).resolve(o.from(), o.to());
        int swept = deleteScratchFiles();
        if (swept > 0) {
            err.println("trace: removed " + swept + " stale scratch file(s) under " + scratch);
        }
        List<Verdict> rows = new ArrayList<>();
        try (WorktreePool pool = new WorktreePool(runner, repo, scratch, o.keepWorktrees())) {
            Optional<TaskKey> previousGood = Optional.empty();
            Path previousHashes = null;
            boolean bazelAlive = impacts != null;
            for (Commit commit : commits) {
                Path worktree = pool.checkout(commit);
                Optional<TaskKey> key = Optional.empty();
                Optional<String> error = Optional.empty();
                try {
                    key = Optional.of(keys.keyFor(worktree, o.taskPath()));
                } catch (ProviderException e) {
                    error = Optional.of(e.getMessage());
                }
                BazelStatus bazel = BazelStatus.NONE;
                if (bazelAlive) {
                    try {
                        Path hashes = impacts.hashes(worktree, scratch.resolve("hashes-" + commit.shortSha() + ".json"));
                        if (previousHashes != null) {
                            Set<String> impacted = impacts.impactedTargets(previousHashes, hashes);
                            bazel = impacted.contains(o.bazelTarget()) ? BazelStatus.IMPACTED : BazelStatus.CLEAN;
                        }
                        previousHashes = hashes;
                    } catch (ProviderException e) {
                        err.println("trace: bazel-diff unavailable: " + e.getMessage());
                        bazelAlive = false;
                        bazel = BazelStatus.NOT_AVAILABLE;
                    }
                } else if (impacts != null) {
                    bazel = BazelStatus.NOT_AVAILABLE;
                }
                rows.add(KeyComparator.verdict(commit, previousGood, key, error, bazel));
                if (key.isPresent()) {
                    previousGood = key;
                }
                if (!o.keepWorktrees()) {
                    pool.release(worktree);
                }
            }
        }
        if (!o.keepWorktrees()) {
            deleteScratchFiles();
        }
        String tsv = TableRenderer.renderTsv(rows);
        if (o.tsv()) {
            out.print(tsv);
        } else {
            out.print(TableRenderer.render(o.taskPath(), impacts == null ? null : o.bazelTarget(), rows));
        }
        if (o.tsvOut() != null) {
            try {
                Files.writeString(o.tsvOut(), tsv);
            } catch (IOException e) {
                throw new ProviderException("cannot write " + o.tsvOut() + ": " + e.getMessage(), e);
            }
        }
        if (rows.stream().anyMatch(v -> v.status() == Status.BUILD_FAILED)) {
            return EXIT_TOOL_FAILURE;
        }
        return rows.stream().anyMatch(v -> v.status() == Status.CHANGED) ? EXIT_CHANGED : EXIT_OK;
    }

    /** Deletes bazel-diff hash and impacted-target files under the scratch root; returns how many went. */
    private int deleteScratchFiles() {
        if (!Files.isDirectory(scratch)) {
            return 0;
        }
        int count = 0;
        try (Stream<Path> entries = Files.list(scratch)) {
            for (Path p : entries.toList()) {
                String name = p.getFileName().toString();
                if (Files.isRegularFile(p) && (name.startsWith("hashes-") || name.endsWith(".impacted.txt"))) {
                    Files.deleteIfExists(p);
                    count++;
                }
            }
        } catch (IOException ignored) {
            // best effort
        }
        return count;
    }

    private int at(Options o, PrintStream out) throws UsageException, ProviderException {
        Commit commit = new RevisionRange(runner, repo).resolveOne(o.at());
        try (WorktreePool pool = new WorktreePool(runner, repo, scratch, o.keepWorktrees())) {
            TaskKey key = keys.keyFor(pool.checkout(commit), o.taskPath());
            out.println(key.taskPath() + " at " + commit.shortSha() + " " + commit.subject());
            out.println("key: " + key.key());
            out.println("implementation: " + key.implementation());
            key.valueFingerprints().forEach((property, hash) -> out.println("value " + property + ": " + hash));
            key.fileFingerprints().forEach((property, files) -> {
                out.println("files " + property + ":");
                files.forEach((path, hash) -> out.println("  " + KeyComparator.displayName(path) + "  " + hash));
            });
        }
        return EXIT_OK;
    }
}
```

```java
    private static String[] trace(Cli cli, String app) throws Exception {
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        ByteArrayOutputStream err = new ByteArrayOutputStream();
        int code = cli.run(Cli.Options.parse(new String[] {app, "--from", "HEAD~1", "--to", "HEAD", "--no-bazel", "--tsv"}),
                new PrintStream(out, true, StandardCharsets.UTF_8), new PrintStream(err, true, StandardCharsets.UTF_8));
        String text = out.toString(StandardCharsets.UTF_8);
        assertTrue(code == Cli.EXIT_OK || code == Cli.EXIT_CHANGED, "exit " + code + "\n" + err + "\n" + text);
        String[] rows = text.split("\n");
        assertEquals(2, rows.length, text);
        return rows[1].split("\t", -1);
    }

    private static void git(ProcessRunner runner, Path cwd, String... args) throws Exception {
        List<String> cmd = new java.util.ArrayList<>(List.of("git"));
        cmd.addAll(List.of(args));
        ProcessRunner.Result r = runner.run(cwd, Duration.ofMinutes(1), cmd);
        assertTrue(r.ok(), String.join(" ", cmd) + " failed: " + r.firstErrorLine());
    }

    /** True when any path segment is a Gradle output dir (`build`, `.gradle`); `build.gradle.kts` and `build-logic` are kept. */
    private static boolean isBuildOutput(Path rel) {
        for (Path segment : rel) {
            String name = segment.toString();
            if (name.equals("build") || name.equals(".gradle")) {
                return true;
            }
        }
        return false;
    }

    private static void copyTree(Path from, Path to) throws IOException {
        try (Stream<Path> paths = Files.walk(from)) {
            for (Path p : paths.toList()) {
                Path rel = from.relativize(p);
                if (isBuildOutput(rel)) {
                    continue;
                }
                Path target = to.resolve(rel);
                if (Files.isDirectory(p)) {
                    Files.createDirectories(target);
                } else {
                    Files.createDirectories(target.getParent());
                    Files.copy(p, target, StandardCopyOption.COPY_ATTRIBUTES);
                }
            }
        }
    }
```
